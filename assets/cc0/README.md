# Modelos libres (CC0)

Modelos 3D de dominio publico para la escenografia de la vista 2.5D: murallas,
torres, portones, pueblo, naturaleza y ruinas. Los personajes y los modelos
principales (el heroe, el yelmo, el Coloso y el reino) siguen siendo de Tripo;
esto es lo que los rodea.

Todos estan bajo CC0 1.0 (dominio publico): se pueden usar, modificar y
publicar sin pedir permiso ni dar credito. Igual se nombra a sus autores, como
ellos sugieren. Cada carpeta lleva el texto de su licencia.
